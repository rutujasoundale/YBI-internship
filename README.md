## Project Description

This project classifies handwritten digits from **0 to 9** using the scikit-learn Digits dataset and a `RandomForestClassifier`.

The notebook includes:

- Loading and visualizing handwritten digit images
- Reshaping 8×8 images into 64 features
- Normalizing pixel values
- Splitting data into training and testing sets
- Training the Random Forest model
- Evaluating results using accuracy and a classification report
